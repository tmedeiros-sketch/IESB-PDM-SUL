# Gerenciador de Despesas 2.0

Projeto Expo / React Native da atividade da Aula 09 (IESB). Inclui Context API, useReducer, AsyncStorage, edição, exclusão, formulário validado, busca, temas e bônus.

## Como executar

Abra um terminal **nesta pasta**, com Node.js LTS instalado:

```powershell
npm install
npx expo install --fix
npx expo start -c
```

Abra com Expo Go (SDK compatível) ou um emulador Android. Se `expo install --fix` modificar versões, inclua o `package-lock.json` gerado no commit.

## Entrega

1. Coloque esta pasta dentro de `praticas/` do seu repositório.
2. Crie a branch `feature/gerenciador-despesas-2.0`.
3. Teste o roteiro de 14 verificações do PDF, incluindo fechar e reabrir o app.
4. Capture prints **reais** da lista clara, da lista escura e do formulário com erros.
5. Faça commit/push e abra o PR incluindo nome, matrícula e prints. Não envie `node_modules`.

**Importante:** o código foi revisado estaticamente; não foi executado em dispositivo neste ambiente.
